SWBC Document Management System

Full-stack document management system built for Senior Design Class

sqlectron - postreSQL AWS - RDS AWS - Dynamo DB Figma Trello

Github Link: https://github.com/Colten-Haggard-dev/SWBCDocumentAPI

Project Overview

For my Senior Design class I chose to work with SWBC and work on a Document Management System with them. Our goal was to use OCR to extract text from sheets and turn them into plain text. I took the role of database admin and was in charge of setting up the server side of the database. I setup both the RDS and noSQL servers for the EC2 Instance. I used sqlectron to see our output just to check if we were getting the right output. We worked with Trello to make sure we were getting our tasks done on time.

Key Features

  • OCR Textract
  • AWS EC2 Instance
  • AWS RDS Server
  • Local Database Hosting on sqlectron
  • API connection to OCR and frontend
  • Docker for applications
🏗️ Technical Architecture
The application follows a three-tier architecture with a Spring Boot backend, MySQL database, and responsive frontend. RESTful APIs handle all client-server communication, ensuring scalability and maintainability.
💡 Challenges & Solutions
Challenge: Getting tasks assigned.

Solution: Staying in communication with both SWBC and my team to ensure tasks were being completed on time. While working independently on learning just in case we got assigned tasks on the fly.

Learning Outcomes

  • Gained experience with SWBC with official deadlines and real-life problems
  • Sprint planning with SWBC
  • Working with little info and making the most out of what we got
  • Working solo with Database configuration with AWS
