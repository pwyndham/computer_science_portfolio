Project Overview

Brogue Like was a mini project I had in my Game Development class. I was tasked with creating an isometric view rogue-like game. We were tasked with creating some models in Blender, and another focus on this project was triggers. Triggers including win and loss conditions, as well as unlocking the door and being able to go in the elevator.

🏗️ Technical Architecture
The game is built in Unity Engine with C# scripting, focusing on Unity's trigger and collision systems. The isometric camera view was configured to provide the classic roguelike perspective. 3D assets including environmental pieces were created in Blender and imported into Unity. The core game logic revolves around Unity's trigger system (OnTriggerEnter/OnTriggerExit) to detect player interactions with doors, elevators, and objective items. Event-driven architecture handles win/loss conditions when specific triggers are activated. VSCode was used as the IDE for all C# script development. This mini-project served as an exercise in understanding Unity's physics system and event-based programming patterns.
💻 Code example
Player.cs C# / Unity 
using UnityEngine;
using UnityEngine.SceneManagement;

public class Player : MonoBehaviour
{
    public GameObject leftDoor;
    public GameObject rightDoor;
    CharacterController characterController;
    public PlayerInventory playerInventory;

    Vector3 resetTransform;

    [Header("Audio")]
    public AudioSource audioSource;
    public AudioClip hitWallSFX;
    

    void Awake()
    {
        characterController = GetComponent();
        
         if (playerInventory == null) {

         playerInventory = GetComponent();
         }
    }
   

    public void moveWithCharacterController(Vector3 direction) {
        GetComponent().Move(direction);
        resetTransform = transform.position;
    }

    public void moveBackAfterCollision(Vector3 direction) {
        
        characterController.enabled = false;
        transform.position = resetTransform;
        characterController.enabled = true;
        Debug.Log("Moving back");
    }
    
    public void bounceOffWall(Vector3 resetTransform) {
        
        audioSource.resource = hitWallSFX;
        audioSource.Play();
        moveBackAfterCollision(resetTransform);
        Debug.Log(resetTransform);
        
    }

    private void OnControllerColliderHit(ControllerColliderHit hit) {
        HitWallCollider(hit);
        HitElevatorFloorCollider(hit);
        HitDoorCollider(hit);
    }

    private void HitDoorCollider(ControllerColliderHit hit)
    {
         if (hit.gameObject.CompareTag("Door")) {
            
            bool hasKey = playerInventory.checkForKey();

            if (hasKey) {
                OpenDoors();
            } else {
            bounceOffWall(resetTransform);
            Debug.Log("You don't have a key!");
            }
        }
    }

    private void OpenDoors()
    {   
        leftDoor.transform.position = new Vector3(-4.04f,0.829f,-.8145f);
        rightDoor.transform.position = new Vector3(-4.04f,0.829f,.95f);
   
    }

    public void HitWallCollider(ControllerColliderHit hit) {
        if (hit.gameObject.CompareTag("Wall")) {
            
            bounceOffWall(resetTransform);
            Debug.Log("Bounce off wall");
        }
    }

    public void HitElevatorFloorCollider(ControllerColliderHit hit) {
        if (hit.gameObject.CompareTag("Elevator")) {
            Debug.Log("you win");
            SceneManager.LoadScene("Win Screen");
            
        }
    }
    public void OnTriggerEnter(Collider other)
    {
        HitTrapTrigger(other);
        HitKeyTrigger(other);
    }
    public void HitKeyTrigger(Collider other) {
        if (other.gameObject.CompareTag("Key")) {
            
            GameObject key = other.gameObject;
            if (playerInventory != null) {
                playerInventory.addToInventory(key);

           
            key.transform.SetParent(transform);
            key.transform.localPosition = new Vector3(0f, .65f, 3.68f); 
            Debug.Log("Key local position: " + key.transform.localPosition);
            Debug.Log("You picked up a key");

            } else {
                Debug.Log("Playerinventory is null");
            }
        }
    }

    public void HitTrapTrigger(Collider other) {
        if (other.gameObject.CompareTag("Trap")) {
            Debug.Log("You stepped on trap...");
            SceneManager.LoadScene("Lose Screen");

        }
    }
}
💡 Challenges & Solutions
Challenge: Implementing reliable trigger detection in an isometric view where player movement and collision boxes needed precise configuration.

Solution: Carefully configured collider sizes and trigger zones to ensure consistent detection. Used Unity's layer system to filter which objects should trigger interactions. Tested extensively with different approach angles to ensure triggers activated reliably from all directions in the isometric space.
