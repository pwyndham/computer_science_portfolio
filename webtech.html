Project Overview

For my Web Technologies class, over the course of the semester I used AWS Free tier server and created an EC2 instance. I used the Ubuntu Linux distro, and accessed it via Command line, where I would ssh to the pem file provided by AWS. I installed PHP and MySQL on the server and used PHPMyAdmin to manage the database. I created a website using Adobe Dreamweaver that connected to the database and allowed users to input their contact information which would then be stored in the database. I created different user accounts with different privileges to see how that would affect what users could do on the website and database. The rest of the project was just creating an outline for a personal portfolio. I was given the creative freedom to design the website however I wanted as long as it didn't crash at any given time.

🏗️ Technical Architecture
The website is hosted on AWS EC2 infrastructure running Ubuntu Linux with a LNMP stack (Linux, Nginx, MySQL, PHP). Adobe Dreamweaver was used for frontend development, creating HTML/CSS/JavaScript pages that connect to a MySQL database via PHP. The architecture implements role-based access control through MySQL user accounts with different privilege levels, demonstrating security best practices. SSH access enables remote server administration, while PHPMyAdmin provides a web-based interface for database management and monitoring.

register.php PHP / MySQL 
<?php
// User registration with password hashing and duplicate checking
if(!isset($_POST['submit']))
{
    // Display registration form
    echo '<form method="post" action="">';
    echo '<div class="form-group">';
    echo '<label for="username">Username: </label>';
    echo '<input type="text" name="username" class="form-control"/>';
    echo '</div>';
    echo '<div class="form-group">';
    echo '<label for="password">Password: </label>';
    echo '<input type="text" name="password" class="form-control"/>';
    echo '</div>';
    echo '<button class="btn btn-primary" name="submit">Submit</button>';
    echo '</form>';
}
else
{
    // Process registration
    $username = addslashes($_POST['username']);
    $dblink = db_connect("contact_data");
    
    // Check if username already exists
    $sql = "SELECT `auto_id` FROM `accounts` WHERE `username`='$username'";
    $result = $dblink->query($sql) or
        die("Something went wrong: " . $dblink->error);
    
    if ($result->num_rows > 0) {
        // Username already exists
        redirect("register.php?errMsg=accountExists");
    }
    else {
        // Create new account with hashed password
        $password = $_POST['password'];
        $salt = "CS4413SP25"; // Salt for additional security
        $pwHash = hash('sha256', $salt.$password.$username);
        
        $sql = "INSERT INTO `accounts` (`username`, `hash`) 
                VALUES ('$username', '$pwHash')";
        $dblink->query($sql) or
            die("Something went wrong: " . $dblink->error);
        
        redirect("static_html_output/login.html");
    }
}
?>
💡 Challenges & Solutions
Challenge: Ensuring the website remained stable and didn't crash under various usage scenarios while maintaining database connectivity.

Solution: Implemented proper error handling in PHP scripts, used prepared statements for database queries, and established connection pooling best practices. Monitored server resources and tested extensively to identify potential failure points before deployment.

Challenge: Understanding and implementing MySQL user privilege levels and how they affect database access.

Solution: Created multiple user accounts in PHPMyAdmin with different privilege sets (SELECT only, INSERT/UPDATE, full admin access) and tested each to understand how privilege restrictions impact functionality. This hands-on approach helped solidify understanding of database security and access control.
