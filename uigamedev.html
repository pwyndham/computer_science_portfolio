Project Overview

In my User Interfaces class, some classmates and I grouped up for the final project. We all had common interests in wanting to make a game instead of making an e-commerce application. We had a bit of time do design wireframes, the overall project structure and then the final month is when we could start coding the game. I was the logic designer for this project. I designed the game's logic flow, and created most of the game's UI. My other classmates helped with a few interfaces, external documents for the assignments and the fighting logic. We used Unity Cloud and the built-in version control to manage our project files. In Unity we used their UAP screen reader for accessibility features.

  • Inventory management system with drag-and-drop functionality

  • Complete wireframing and design documentation in Figma
🏗️ Technical Architecture
The game is built in Unity Engine with C# scripting for all UI logic and game flow. The project started with extensive design planning in Figma, where wireframes and UI flow diagrams were created before any coding began. Unity Cloud with built-in version control was used for team collaboration, allowing multiple developers to work simultaneously on different aspects of the project. The UI system utilizes Unity's Canvas and UI toolkit for responsive layout management. Accessibility was a core focus, implemented through Unity's UAP (Universal Accessibility Plugin) screen reader integration to ensure the game is playable by users with visual impairments. The architecture follows a modular design pattern with separate UI managers for settings, inventory, combat, and character systems. VSCode was used as the primary IDE for C# script development.

using UnityEngine;
using TMPro;
using UnityEngine.UI;

public class ClassSelectionHandler : MonoBehaviour
{

    public Button fighterButton, mageButton, medicButton, assassinButton;
    public TMP_Text classText;
    public Button confirmButton;

    void Start()
    {
        fighterButton.onClick.AddListener(() => {SelectClass("Fighter");});
        mageButton.onClick.AddListener(() => {SelectClass("Mage");});
        medicButton.onClick.AddListener(() => {SelectClass("Medic");});
        assassinButton.onClick.AddListener(() => {SelectClass("Assassin");});
        confirmButton.onClick.AddListener(() => {SetClassValues(classSelected); Debug.Log(classSelected + PlayerAttributesData.strength + PlayerAttributesData.intelligence +
            PlayerAttributesData.dexterity +
            PlayerAttributesData.agility +
            PlayerAttributesData.constitution +
            PlayerAttributesData.perception);   });
    }

    void SelectClass(string className)
    {
        classText.text = className;
        classSelected = className;
    }

    void SetClassValues(string classSelected)
    {
        PlayerAttributesData.currency = 120;
        switch(classSelected)
        {
            case "Fighter":
            // strength = 
            PlayerAttributesData.characterClass = "Fighter";
            PlayerAttributesData.strength = 4;
            PlayerAttributesData.intelligence = 4;
            PlayerAttributesData.dexterity = 4;
            PlayerAttributesData.agility = 4;

💡 Challenges & Solutions
Challenge: Coordinating team collaboration on a Unity project with multiple developers working on different UI systems simultaneously.

Solution: Utilized Unity Cloud's built-in version control system to manage concurrent development. Established clear ownership of different UI systems (I handled logic flow and most UI design, teammates handled fighting logic and supporting interfaces). Regular team meetings and documentation ensured everyone stayed aligned with the overall design vision established in Figma wireframes.

Challenge: Implementing comprehensive accessibility features to make the game playable for users with visual impairments.

Solution: Integrated Unity's UAP (Universal Accessibility Plugin) screen reader throughout all UI elements. Ensured every interactive element had appropriate accessibility descriptions and feedback. Tested the screen reader functionality across all game screens to verify complete navigation without visual cues. This required careful planning of UI hierarchy and navigation flow.

Challenge: Designing a complex UI system with multiple interconnected menus while maintaining intuitive user flow.

Solution: Started with comprehensive wireframing in Figma before any implementation, mapping out all UI screens, transitions, and logic flows. This planning phase allowed us to identify and resolve navigation issues early in the design process. Created a modular UI manager system that could handle panel switching cleanly and consistently across all game states.
